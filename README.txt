AUTO PROMO - proiect de pornire pentru GitHub Pages

PUBLICARE:
1. Dezarhiveaza arhiva.
2. In repository-ul GitHub, apasa Add file > Upload files.
3. Incarca TOATE fisierele din acest folder (nu folderul ZIP).
4. Apasa Commit changes.
5. Intra la Settings > Pages.
6. La Build and deployment alege Deploy from a branch.
7. Alege branch main si folder / (root), apoi Save.
8. Deschide linkul afisat in sectiunea Pages.

LIMITARI:
- Anunturile sunt demonstrative.
- Formularul nu salveaza si nu trimite anunturi.
- Nu exista conturi, baza de date sau incarcare de fotografii.
- Fotografia de fundal este incarcata de la Unsplash si necesita internet.
- Pentru anunturi reale trebuie conectat un backend si o baza de date.
